# Online-Doctor-Finder-

QuickHealer – Online Doctor Appointment Booking System 

QuickHealer is a modern, user-friendly healthcare web application designed to simplify doctor appointment booking. It provides separate interfaces for patients, doctors, and administrators, enabling patients to find doctors and book appointments, administrators to manage and approve appointment requests, and doctors to view approved appointments and notifications.

The project includes doctor profiles, specialization-based search, appointment management, emergency assistance UI, role-based login, notifications, and a responsive interface. It uses demo data for development and testing, with persistent appointment data where supported.

Tech Stack: HTML, CSS, JavaScript, and MySQL (planned or integrated, depending on the current implementation).

Project Type:Healthcare Web Application | Frontend Development | Academic Project
